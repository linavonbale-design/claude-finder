# Claude Finder roadmap

## V0.1 — working local MVP
- Chrome extension
- Import history
- Local keyword search

## V0.2 — the differentiator
- Extract decisions, rejected alternatives, reasons, dates
- Search by meaning, not exact words
- "What changed?" timeline
- Highlight conflicting decisions
- Every answer links back to evidence

## V0.3 — multi-AI
- Claude
- ChatGPT
- Gemini
- Cursor / Claude Code where locally available

## V0.4 — Product Hunt-ready
- polished side panel
- onboarding
- privacy dashboard
- demo dataset
- analytics only with explicit opt-in
- landing page and launch assets

## Important
Do not promise a Product Hunt win. The goal is a differentiated, useful product with a strong demo.
